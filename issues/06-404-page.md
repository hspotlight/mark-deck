# 06 — 404 Page

**Group:** A – Non-Login User
**Type:** AFK
**Blocked by:** #01 Project Scaffold

---

## What to build

A custom 404 page shown for all unknown routes and explicitly rendered by the public deck viewer (#04) and author profile page (#05) when a deck or user is not found. Also covers deleted deck URLs.

---

## Acceptance criteria

### Page
- [ ] `app/not-found.tsx` created — Next.js App Router automatically uses this for unmatched routes
- [ ] Displays a short, friendly message: e.g. *"This page doesn't exist or was removed"*
- [ ] "Go to homepage" button links to `/`
- [ ] On-brand design using mark-deck colors and Inter typeface — not a plain white error page
- [ ] HTTP status code is 404 (Next.js handles this automatically via `not-found.tsx`)

### Programmatic 404
- [ ] `notFound()` from `next/navigation` is called in #04 (deck viewer) and #05 (profile page) when the resource is missing or private — confirmed to render the same `not-found.tsx`

### Tests
- [ ] Playwright: navigate to `/this-route-does-not-exist` → assert 404 message visible and status code is 404
- [ ] Playwright: navigate to `/nonexistent-user/nonexistent-slug` → assert 404 message visible

---

## Implementation notes

- Keep this simple — a single `app/not-found.tsx` file. No need for a separate component.
- No auth state needed on this page. It must work for unauthenticated users.
